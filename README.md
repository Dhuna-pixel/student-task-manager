# 🎓 Student Task Manager

A cloud-based student task management web application that helps students organize academic tasks based on **deadlines, priority, and completion status**.

The application provides complete **CRUD (Create, Read, Update, Delete)** functionality through RESTful APIs and stores task data in a cloud-hosted MongoDB Atlas database.

## 🌐 Live Application

- **Frontend:** https://student-task-manager-lilac.vercel.app
- **Backend API:** https://student-task-backend-wmkv.onrender.com/api/tasks

## 🎯 Problem Statement

Students often manage assignments across different platforms, which can lead to missed deadlines, poor prioritization, and difficulty tracking completed work.

The Student Task Manager provides a centralized system for managing academic tasks and tracking their progress.

## ✨ Features

- Create, view, update, and delete tasks
- Track deadlines
- Set priority: Low, Medium, High
- Track status: Pending, In Progress, Completed
- Cloud-hosted database

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript, Vercel
- **Backend:** Node.js, Express.js, Mongoose, Render
- **Database:** MongoDB Atlas
- **Version Control:** Git, GitHub
