# 🎓 Student Task Manager

A full-stack MERN (MongoDB, Express, React/Vanilla JS, Node.js) task management web application built to help students organize assignments, track priorities, and manage deadlines.

---

## 🌐 Live Demo

* **Frontend App:** [https://student-task-manager-lilac.vercel.app](https://student-task-manager-lilac.vercel.app)
* **Backend API:** [https://student-task-backend-wmkv.onrender.com/api/tasks](https://student-task-backend-wmkv.onrender.com/api/tasks)

---

## ✨ Features

* **Create Tasks:** Add tasks with titles, course codes, due dates, and priority levels.
* **View Tasks:** Real-time fetching of saved tasks from MongoDB Atlas.
* **Delete Tasks:** Remove completed or obsolete tasks.
* **Responsive Design:** Fully functional across desktop, tablet, and mobile browsers.

---

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Vercel
* **Backend:** Node.js, Express.js, Render
* **Database:** MongoDB Atlas (Mongoose ORM)
* **Version Control:** Git, GitHub
